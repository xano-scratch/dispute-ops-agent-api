Dispute Ops Agent API

One governed rule layer for a bank's chargeback disputes, called the same way by a human ops operator and by an AI agent. The agent proposes. The rule layer decides. Every action lands in one audit trail.

What it proves

The agent is a governed caller

The AI triage endpoint reads a case and proposes a resolution inside the policy it is handed. It proposes only. It never writes the final resolution.

One rule for people and agents

The apply endpoint checks the caller's role, the caller's self-resolve limit, and the reason code's ceiling. An over-ceiling resolution is refused for the agent and for a non-supervisor human alike.

API-layer permissions, not RLS

Auth is an auth table, token minting, and per-endpoint role guards. The rule a reviewer reads in the code is the rule the engine runs.

One shared audit trail

Each governed action writes one row, tagged human or agent. The dispute detail shows the human and agent steps interleaved in time.

API surface

MethodPathWhat it enforces
POST/api:dispute/seedBootstraps demo data, returns a token per identity. Idempotent.
POST/api:dispute/loginExchanges email and password for a token.
POST/api:dispute/cases/openOpens a dispute after checking the reason code has a rule.
POST/api:dispute/triageThe AI agent classifies and proposes the allowed resolution. Proposes only.
POST/api:dispute/cases/resolveApplies a resolution behind the shared role and limit guard. Writes apply or block.
GET/api:dispute/casesLists disputes, with an optional status filter.
GET/api:dispute/cases/{dispute_id}One case with its transaction, rule, audit trail, and agent runs.

The screens

  • Identity switcher. Act as the human triage operator, the human supervisor, or the AI agent. Every call carries that identity.
  • Dispute queue. The case list by status, plus a form to open a new dispute against a seeded transaction.
  • Dispute detail. The case, its transaction, and the governing rule side by side. Run the AI triage, apply a resolution through the guard, and read the combined human and agent audit trail.
